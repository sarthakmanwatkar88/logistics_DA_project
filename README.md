# Logistics Data Analysis Project

## About the Project

This project focuses on Strategic Planning and Data Exploration in Logistics using Python.

The aim is to analyze delivery operations and identify factors that affect delivery time, delays, delivery failures, and delivery costs.

## Dataset

The project uses a logistics dataset containing:

- 25,000 delivery records
- 15 variables
- Delivery partner information
- Package type
- Vehicle type
- Delivery mode
- Region
- Weather condition
- Distance
- Package weight
- Delivery time
- Expected delivery time
- Delay status
- Delivery status
- Delivery rating
- Delivery cost

## Technologies Used

- Python
- Pandas
- Matplotlib

## Analysis Performed

- Data loading
- Data cleaning
- Missing-value checking
- Duplicate checking
- KPI calculation
- Exploratory Data Analysis
- Delivery partner analysis
- Weather condition analysis
- Regional analysis
- Data visualization

## Key Performance Indicators

The main KPIs analyzed in this project are:

- Average Delivery Time: 6.25 hours
- Average Delivery Cost: 864.94
- Delay Rate: 26.68%
- Failure Rate: 5.31%

## Key Findings

The analysis shows that weather conditions have an important relationship with delivery delays. Stormy and rainy weather have higher delay rates than clear, hot, and cold conditions.

Delivery partners were also compared based on their average delivery time and delay rate. Regional delivery performance was analyzed to identify differences between regions.
